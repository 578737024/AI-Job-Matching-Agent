1. 基于公司 Agent Workflow 产品平台，参与客户业务需求分析、方案设计及 Agent 应用构建实施；

3. 通过低代码 / 无代码方式实现智能体工作流搭建，协助完成解决方案的测试验证；
4. 系统学习智能体技术原理及产品架构，参与行业解决方案研究与实践案例输出；
5. 协助完成客户需求沟通、方案演示及技术培训等实施支持工作；
6. 参与实施文档编写与知识沉淀，包括实施方案、操作手册及问题排查指南。
