# 项目2：AI岗位匹配助手测试记录

## 一、测试目标

本测试用于验证 AI岗位匹配助手 是否能够根据岗位JD和候选人简历，完成岗位类型判断、人岗匹配评分、投递建议、简历优化建议和面试准备建议。

## 二、测试场景

### 测试场景1：Agent应用项目经理岗位

岗位名称：Agent应用项目经理  
岗位方向：Agent应用 / 低代码工作流 / 项目实施  
测试输入：岗位JD + 原始简历  
测试目标：验证智能体是否能够判断岗位适配度，并生成简历优化建议。

## 三、测试结果摘要

- 岗位类型判断：Agent应用项目助理 / 项目经理助理
- 是否属于AI应用落地方向：是
- 匹配度：A / 较匹配
- 是否建议投递：是
- 是否建议主投：是
- 核心匹配原因：
  1. 原始简历中包含Coze工作流搭建项目；
  2. 原始简历中包含RAG知识库问答项目；
  3. 校园和街道经历可以支撑沟通协作、资源协调和文档汇报能力；
  4. 岗位接受应届毕业生，不强制要求复杂代码。

## 四、输出效果评估

### 1. 做得好的地方

- 能识别岗位真实类型；
- 能判断该岗位属于AI应用落地方向；
- 能结合Coze工作流项目进行简历优化；
- 能结合RAG项目补充知识库问答能力；
- 能识别出阶段性出差和技术补强风险。

### 2. 需要优化的地方

- 初始版本曾出现虚构数据和夸大表达；
- 优化后增加真实性边界规则，避免新增原始简历中没有出现的数据、培训、客户交付等内容；
- 后续需要避免输出“系统规则”“关键词引用规则”等内部表达。

## 五、可用于简历的优化结果

### 项目一：基于 Coze 的智能内容生产工作流系统

- 基于 Coze 低代码平台，独立完成智能体工作流全链路搭建，串联语音转文字、大模型改写、封面图生成、公众号推送等节点，实现音频输入到成品发布的端到端自动化流程，将单篇推文制作时间从2小时压缩至30分钟，效率提升75%。

- 设计“机审 + 人审”双层审核机制，通过预设敏感词列表构建条件分支节点，实现内容自动分流，在保障内容安全的前提下降低人工介入频次。

- 针对大模型改写节点开展A/B测试，对比基础指令与角色设定、Few-shot示例的效果，经8轮Prompt迭代，将内容可用率从约70%提升至90%以上。

### 项目二：基于 RAG 的基层事务智能问答与数据统计系统

- 立足村社业务场景，梳理50余类高频咨询问题，收集政策文件与办事指南，经过数据清洗构建结构化问答知识库与台账数据底座。

- 设计并落地RAG检索增强生成问答链路，通过向量检索召回相关文档片段，并结合大语言模型生成回答，降低模型幻觉，累计处理咨询150余次，回答可用率达89%以上。

- 开发台账数据自动化统计模块，利用Python Pandas完成数据分类汇总与可视化图表生成，将手工统计工作从约1小时缩短至5分钟以内，报表用于日常工作汇报与村务公开。

## 六、测试结论

本轮测试说明，AI岗位匹配助手已经能够完成“岗位JD + 原始简历”的定制化简历优化任务。该功能可以作为项目2的核心展示功能之一，用于作品集、项目README和面试演示。

## 测试场景2：Agent应用项目经理岗位面试题生成

### 一、测试目标

验证 AI岗位匹配助手 是否能够根据目标岗位JD和候选人项目经历，生成有针对性的面试问题，并给出回答方向、回答风险和优先准备顺序。

### 二、测试输入

目标岗位：Agent应用项目经理  
岗位方向：Agent应用 / 低代码工作流 / 项目实施 / 客户沟通 / 测试验证  

输入内容包括：
- Agent应用项目经理岗位JD；
- 基于 Coze 的智能内容生产工作流系统；
- 基于 RAG 的基层事务智能问答与数据统计系统。

### 三、测试输出摘要

智能体生成了 8 个高频面试问题，覆盖以下方向：

1. Coze 工作流搭建；
2. RAG 知识库构建；
3. 机审 + 人审审核机制；
4. Prompt A/B 测试与迭代；
5. 客户需求冲突处理；
6. 系统配置与业务逻辑编排；
7. 智能体技术原理和产品架构理解；
8. 测试验证方法。

### 四、输出效果评估

#### 做得好的地方

- 能围绕岗位JD生成问题，而不是泛泛生成通用问题；
- 能结合候选人的 Coze 项目和 RAG 项目；
- 每个问题都包含“为什么会问”和“回答方向”；
- 能识别第三方系统集成、低代码平台经验、大规模数据处理等潜在短板；
- 能给出优先准备顺序。

#### 需要优化的地方

- 候选人短板类问题主要集中在“最容易暴露短板的问题”中，未完全进入前8个主问题；
- 部分回答方向仍偏概括，后续可继续优化为更口语化的面试回答框架；
- 后续可以增加“参考回答示例”模式，但当前版本先保留回答方向，避免生成过度包装的答案。

### 五、测试结论

本轮测试说明，AI岗位匹配助手已经具备面试准备辅助能力，能够基于岗位JD和候选人项目经历生成针对性面试问题、回答方向和风险提醒。该模块可以作为项目2的核心功能之一，用于项目README、作品集展示和后续面试训练。
